# プレイヤーアニメーション音声設定ガイド

## 概要
プレイヤーの歩き、走り、剣の音をアニメーションと連動させるため、アニメーションイベントを使用して音声を再生するように変更しました。

## 変更内容

### スクリプトの変更点
- タイマー方式の足音自動再生を削除
- `PlayAttackSound()` と `PlayFootstepSound()` をpublicメソッドに変更
- アニメーションイベントから呼び出せるように実装

## アニメーションイベントの設定方法

### 1. 攻撃アニメーションに剣の音を追加

1. **Projectウィンドウ**で攻撃アニメーションを選択
   - 通常攻撃: `Attack` アニメーション
   - 溜め攻撃: `ChargeAttack` アニメーション

2. **Animationウィンドウ**を開く (Window > Animation > Animation)

3. 剣が敵に当たるタイミングのフレームを見つける

4. タイムラインの該当フレームを選択し、右上の**イベント追加ボタン**をクリック

5. イベントの設定:
   - **Function**: `PlayAttackSound` を選択
   - パラメータは不要

### 2. 歩行・走行アニメーションに足音を追加

1. **Projectウィンドウ**で移動アニメーションを選択
   - 歩行: `Walk` アニメーション
   - 走行: `Run` アニメーション

2. **Animationウィンドウ**を開く

3. 足が地面に着くタイミングのフレームを見つける
   - 左足が地面に着くフレーム
   - 右足が地面に着くフレーム

4. それぞれのフレームに**イベント追加**

5. イベントの設定:
   - **Function**: `PlayFootstepSound` を選択
   - パラメータは不要
   - スクリプトが自動的に現在のダッシュ状態を判定して適切な音を再生します

### 3. 例: 1秒のWalkアニメーションの場合

```
0.0秒 --------------- 0.5秒 --------------- 1.0秒
  |                     |                     |
  [左足着地]           [右足着地]           [ループ]
  イベント             イベント
  PlayFootstepSound()  PlayFootstepSound()
```

## 使用可能なメソッド

### PlayAttackSound()
- **用途**: 剣を振る音の再生
- **パラメータ**: なし
- **使用するアニメーション**: Attack, ChargeAttack など攻撃系

### PlayFootstepSound()
- **用途**: 足音の再生
- **パラメータ**: なし
- **自動判定**: isDashing フラグを自動で確認し、歩行音か走行音を選択
- **使用するアニメーション**: Walk, Run, Idle→Walk遷移 など移動系

## メリット

1. **正確な同期**: アニメーションのフレームに合わせて音が再生される
2. **音の重複なし**: アニメーションイベントで制御されるため、音が重なる心配がない
3. **調整が簡単**: アニメーションエディタで視覚的にタイミングを調整可能
4. **パフォーマンス向上**: 不要なタイマー処理を削除

## 注意事項

- アニメーションループする場合、ループの開始と終了で音が二重に再生されないように注意
- アニメーション速度を変更した場合、音の再生タイミングも自動的に調整される
- Blendツリーを使用している場合、各アニメーションクリップに個別にイベントを設定する必要がある

## トラブルシューティング

### 音が再生されない場合
1. AudioClipがインスペクターで設定されているか確認
   - `se_sword09` (剣の音)
   - `walk_on_floor1` (歩行音)
   - `run1` (走行音)
2. アニメーションイベントの関数名が正確か確認
3. Consoleでエラーが出ていないか確認

### 音が二重に再生される場合
- アニメーション遷移中に両方のアニメーションでイベントが発火している可能性
- 遷移時間を調整するか、Exit Timeを設定する

### 走行音が再生されない場合
- isDashing フラグが正しく設定されているか確認
- ダッシュ入力(Shift)が正しく機能しているか確認
